Impostazioni Applicazione

Configura i parametri dell'applicazione, inclusa la chiave API per le funzionalità di intelligenza artificiale reale.

Configurazione Intelligenza Artificiale

Scegli il provider IA e inserisci la chiave API per analizzare foto reali delle piante.

Nota: Le chiavi vengono salvate nella sessione corrente del tuo browser o lette dalle variabili d'ambiente. Non vengono salvate in database pubblici.

Come ottenere le chiavi API?

OpenAI: Vai su OpenAI Platform → API Keys.
Google: Vai su Google AI Studio → Get API Key.

Dettagli Tecnici dell'Applicazione

Questa applicazione è interamente programmata in Python utilizzando il framework leggero Flask. Il database locale in cui risiedono i dati delle tue piante e i compiti è memorizzato in un file SQLite chiamato plants.db, creato automaticamente nella cartella dell'applicazione.

Le immagini caricate vengono salvate in locale sotto la cartella static/uploads/.
